# 🍬 Jelly Belly Automation Framework (Java + Selenium) — Hybrid Model

This repository contains a **Hybrid Automation Testing Framework** for the **Jelly Belly Web Application**, developed using **Java + Selenium WebDriver** with **TestNG + Maven** following **Page Object Model (POM)** design.

The framework is structured to be scalable, reusable, and easy to maintain for UI automation testing.

---

## ✅ Tech Stack / Tools Used

- **Java**
- **Selenium WebDriver**
- **TestNG**
- **Maven**
- **Page Object Model (POM)**
- **Hybrid Framework (POM + Modules + Utilities + Data Providers)**
- **Git / GitHub**
- *(Optional)* Excel Report Generator (`generateReportInExcel`)
